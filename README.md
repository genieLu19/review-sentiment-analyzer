# Review Sentiment Analyzer

ML-проект для классификации тональности пользовательских отзывов. Система получает текст отзыва и определяет его настроение: `positive`, `neutral` или `negative`.

## Зачем нужен проект

Отзывы пользователей часто содержат полезные сигналы для продукта: что нравится, что вызывает раздражение, какие тексты требуют внимания поддержки или аналитика. Такой классификатор можно использовать как первый слой автоматической обработки отзывов:

- быстро отделять негативные отзывы от нейтральных и положительных;
- отслеживать динамику настроения пользователей;
- готовить данные для дашборда поддержки или продуктовой аналитики;
- находить проблемные тексты без ручного просмотра всей выборки.

## Что реализовано

- загрузка CSV-датасета с отзывами;
- предобработка текста: нижний регистр, нормализация `ё`, удаление пунктуации;
- TF-IDF-векторизация текста;
- обучение модели `LogisticRegression` из `scikit-learn`;
- разбиение данных на train/test;
- расчет `accuracy`, `precision`, `recall`, `f1-score`;
- сохранение обученной модели в `models/sentiment_model.joblib`;
- сохранение отчета в `reports/metrics.json`;
- CLI-команда для предсказания тональности нового отзыва;
- тесты для функции очистки текста.

## ML-постановка

Тип задачи: **многоклассовая классификация текста**.

Целевая переменная: `sentiment`.

Классы:

| Класс | Значение |
| --- | --- |
| `positive` | положительный отзыв |
| `neutral` | нейтральный или смешанный отзыв |
| `negative` | негативный отзыв |

Базовая модель:

```text
Raw review text -> text cleaning -> TF-IDF -> Logistic Regression -> sentiment class
```

## Быстрый старт

Команды ниже рассчитаны на PowerShell.

```powershell
cd "C:\Users\Varya\Documents\Codex\2026-07-16\d\review-sentiment-analyzer"
```

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Установить зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Обучить модель:

```powershell
$env:PYTHONPATH="src"
.\.venv\Scripts\python.exe -m sentiment_analyzer.train --data data/sample_reviews.csv --model-path models/sentiment_model.joblib --report-path reports/metrics.json
```

Сделать предсказание:

```powershell
$env:PYTHONPATH="src"
.\.venv\Scripts\python.exe -m sentiment_analyzer.predict --model-path models/sentiment_model.joblib --text "Книга очень понравилась, читается легко и интересно"
```

Пример вывода:

```text
Текст: Книга очень понравилась, читается легко и интересно
Тональность: positive
Уверенность: 0.36
```

Запустить тесты:

```powershell
$env:PYTHONPATH="src"
.\.venv\Scripts\python.exe -m pytest
```

## Данные

В репозитории используется демонстрационный датасет:

```text
data/sample_reviews.csv
```

Формат:

| Поле | Описание |
| --- | --- |
| `text` | текст пользовательского отзыва |
| `sentiment` | целевой класс тональности |

Текущий датасет небольшой и нужен для демонстрации полного ML-пайплайна. Для продуктового применения его нужно заменить или расширить реальными отзывами.

## Метрики

После обучения создается файл:

```text
reports/metrics.json
```

В нем сохраняются:

- размер train/test выборок;
- `accuracy`;
- `precision`, `recall`, `f1-score` по каждому классу;
- macro/weighted averages.

На демонстрационном датасете текущий запуск дал:

```text
Accuracy: 0.250
Train size: 22
Test size: 8
```

Низкая точность ожидаема: датасет специально маленький, поэтому качество модели ограничено количеством обучающих примеров. Ценность проекта на текущем этапе - в воспроизводимом пайплайне, структуре кода и понятной базе для дальнейшего улучшения.
